# TdxNet.Service

**通达信行情数据 · 本地 WebAPI 服务**

把通达信行情数据封装成本机 HTTP / WebSocket 接口，在 `http://127.0.0.1:8888` 上提供数据服务，供同一台计算机上的浏览器、脚本程序、客户端软件或自动化工具调用。

## 特性

- **本地 HTTP 服务**：以状态栏图标方式常驻后台，把行情服务封装为本地 WebAPI，接口仅提供 `GET` / `POST` 两种请求方式，返回统一 JSON。
- **完整行情覆盖**：实时行情快照（含五档）、K 线（分钟~年，含前/后复权）、分时、分笔、集合竞价、证券代码表、指数、板块与概念、除权除息、F10 公司信息、扩展行情（期货 / 港股）。
- **实时推送**：内置 `WebSocket` 端点，支持订阅式五档行情推送（`ws://…/ws/quote`），另有 `ws://…/ws` 回显端点用于链路验证。
- **涨跌停扫描**：后台引擎批量扫描沪深 A 股与北交所标的，实时计算涨停 / 跌停 / 开板 / 接近涨跌停，并自动剔除新股等无涨跌幅限制标的。
- **内置接口测试台**：随程序发布的零依赖单文件网页，可视化调试全部接口并生成对接代码。
- **无外部依赖运行**：单文件可执行程序，双击即用，无需安装运行时或额外配置文件。

> 程序本身不产生、不发布任何行情数据，也不提供行情数据源，**仅提供数据的转发通道**。

## 快速开始

1. 从[官网](https://tdxnet.v2stock.com)下载 `TdxNet.Service.exe`。
2. 双击运行 —— 程序**只在状态栏（系统托盘）显示图标，不占用任务栏**。
3. 右键托盘图标 → **设置**，添加 / 选择行情服务器，必要时「检测选中」确认连通性。
4. 右键托盘图标 → **启动服务**（需已完成[注册](#软件注册)）。
5. 浏览器访问 `http://127.0.0.1:8888/api/status` 验证服务是否在线。

## 软件注册

软件需注册后方可使用（注册含有效期）。**注册到期后无法启动服务**，但仍可使用「测试」功能验证数据获取。

右键托盘图标 → 「设置」→ 「软件注册」选项卡，记录**设备码**，再选择一种注册方式：

| 注册方式 | 说明 |
|---------|------|
| **在线注册** | 输入获取的激活码（卡券号）→ 点击「注册」。（推荐） |
| **离线注册（注册码注册）** | 将获得的注册码完整粘贴到注册码区域 → 点击「注册」 |
| **导入注册文件** | 点击「选择文件…」选择获得的注册文件完成注册 |

「软件注册」选项卡同时提供：注册状态（复制设备码 / 反注册）与官方购买地址（月卡 / 年卡 / 永久）。

## API 通用约定

**请求**

- 服务地址：`http://<监听地址>:<端口>`，本机访问用 `http://127.0.0.1:8888`
- 方法：仅 `GET` 与 `POST`（GET 用查询字符串，POST 用 JSON body）
- WebSocket：`ws://<监听地址>:<端口>/ws`、`ws://<监听地址>:<端口>/ws/quote`

**响应格式**（所有接口统一）

```json
{ "ok": true,  "data": ... }        // 成功
{ "ok": false, "msg": "错误信息" }   // 失败
```

> **字段命名**：外层包装键 `ok` / `msg` / `data` 与请求参数均为**全小写**；`data` 内部字段除涨跌停扫描系列（`/api/limit/*`，全小写）外，均沿用 **PascalCase**（如 `Market` / `Code` / `Price`）。

**跨域（CORS）**：服务对所有来源开放 CORS（`Access-Control-Allow-Origin: *`），因此以 `file://` 打开的测试页也能直接调用本机接口。

**市场代码（market）**

| 值 | 市场 | 值 | 市场 |
|----|------|----|------|
| 0 | 深圳 | 2 | 北京（北交所） |
| 1 | 上海 | | |

**K 线类型（category）**

| 值 | 含义 | 值 | 含义 |
|----|------|----|------|
| 0 | 5 分钟 | 7 | 扩展 1 分钟 |
| 1 | 15 分钟 | 8 | 1 分钟 |
| 2 | 30 分钟 | 9 | 日 K（RI） |
| 3 | 1 小时 | 10 | 3 月 |
| 4 | 日 K | 11 | 年 K |
| 5 | 周 K | | |
| 6 | 月 K | | |

**复权口径（mode）**

| 值 | 含义 |
|----|------|
| 0 | 分红再投资（默认） |
| 1 | 只还原送转 |
| 2 | 分红直接加回 |

### 涨跌停扫描

| 方法 | 路径 | 说明 |

| GET | `/api/limit/up` | 涨停个股 |
| GET | `/api/limit/down` | 跌停个股 |
| GET | `/api/limit/opened` | 涨停开板 + 跌停开板 |
| GET | `/api/limit/unlimited` | 今日不设涨跌幅限制个股（已剔除出涨跌停） |

## WebSocket 实时推送

把 HTTP 的 `http://` 换成 `ws://` 即可，如 `ws://127.0.0.1:8888/ws/quote`（非 WebSocket 请求访问这两条路径返回 `400`）。

**订阅流程**

1. 建立 WebSocket 连接；
2. 发送 `subscribe` 帧（**追加式**，可多次发送，单批建议 ≤80 只）；
3. 收到 `subscribed` 回执后，有行情即推 `quote` 帧；
4. 不需要时发 `unsubscribe` / `unsubscribe_all`，或直接断开。

**入站帧**（客户端 → 服务端）

```json
{"action":"subscribe","stocks":[{"Market":1,"Code":"600519"},{"Market":0,"Code":"000001"}]}
{"action":"unsubscribe","stocks":[{"Market":0,"Code":"000001"}]}
{"action":"unsubscribe_all"}
{"action":"ping"}
```

**出站帧**（服务端 → 客户端）

| action | 携带字段 | 说明 |
|--------|----------|------|
| `quote` | `ts`、`data`（分片时另有 `seq` / `total`） | 行情帧，`data` 字段与 `/api/quote` **完全一致** |
| `subscribed` | `ts`、`msg` | 订阅成功回执 |
| `pong` | `ts` | 对 `ping` 的回应 |
| `error` | `ts`、`msg` | 订阅失败或帧非法 |

> 帧**自身的键**为全小写；`stocks` 数组元素（`Market` / `Code`）与 `data` 数组元素仍是 **PascalCase**。`ts` 为 Unix 毫秒时间戳。

**容量与分片**

| 项 | 值 |
|----|----|
| 单连接订阅上限 | 8000 只（超限整帧拒绝并回 `error`） |
| 入站帧大小上限 | 1 MB |
| 出站分帧阈值 | 500 只/帧（超过时拆帧，各帧 `ts` 相同、`seq` 递增） |
| 上游拉取 | 按 80 只/批分批，连接池自适应，订阅几百至数千只无需客户端特殊处理 |

**推送节奏**

| 时段 | 推送行为 |
|------|----------|
| 行情活跃时段 `09:15–11:30`、`13:00–15:00` | 每 **3 秒**一轮，实时拉取并广播五档行情 |
| 其中开盘集合竞价 `09:15–09:25`、静默期 `09:25–09:30` | **同样按 3 秒推送**（主站确有实时数据） |
| 非活跃时段（午休 / 盘后 / 周末 / 节假日） | 不联网拉取；新订阅或订阅变更时**立即补推一帧最后快照** |

> 活跃时段前后各留 30 秒边界冗余。断开后订阅即被清除，重连需**重新发送 `subscribe`**。

## 调用示例

以下示例假设服务运行在 `http://127.0.0.1:8888`。

**单只行情**

```bash
curl "http://127.0.0.1:8888/api/quote?market=1&code=600000"
```

```json
{
  "ok": true,
  "data": {
    "Market": 1, "Code": "600000", "Name": "浦发银行",
    "Price": 9.85, "LastClose": 9.80, "Open": 9.82,
    "High": 9.90, "Low": 9.78, "Vol": 523100,
    "Amount": 515200000.0, "ChangePercent": 0.51
  }
}
```

**日 K 线（最近 10 根）**

```bash
curl "http://127.0.0.1:8888/api/kline?category=4&market=1&code=600000&start=0&count=10"
```

**批量行情（POST）**

```bash
curl -X POST "http://127.0.0.1:8888/api/quote/batch" \
  -H "Content-Type: application/json" \
  -d '{"stocks":[{"market":1,"code":"600000"},{"market":0,"code":"000001"}]}'
```

**Python（HTTP）**

```python
import requests

BASE = "http://127.0.0.1:8888"

r = requests.get(f"{BASE}/api/quote", params={"market": 1, "code": "600000"})
print(r.json())

r = requests.get(f"{BASE}/api/kline",
                 params={"category": 4, "market": 1, "code": "600000", "start": 0, "count": 100})
for b in r.json()["data"][:5]:
    print(b["DateTimeStr"], b["Close"])
```

**Python（WebSocket 订阅）**

```python
import json
from websocket import create_connection        # pip install websocket-client

ws = create_connection("ws://127.0.0.1:8888/ws/quote")
ws.send(json.dumps({"action": "subscribe",
                    "stocks": [{"Market": 1, "Code": "600519"},
                               {"Market": 0, "Code": "000001"}]}))

for _ in range(10):
    frame = json.loads(ws.recv())
    if frame["action"] != "quote":
        print("回执：", frame)                  # subscribed / pong / error
        continue
    for q in frame["data"]:
        print(q["Code"], q["Name"] or "-", q["Price"], q["ChangePercent"], "%")

ws.send(json.dumps({"action": "unsubscribe_all"}))
ws.close()
```

**JavaScript / Node**

```js
const ws = new WebSocket('ws://127.0.0.1:8888/ws/quote');
ws.onopen = () => ws.send(JSON.stringify({
  action: 'subscribe', stocks: [{ Market: 1, Code: '600519' }],
}));
ws.onmessage = (e) => {
  const f = JSON.parse(e.data);
  if (f.action === 'quote') f.data.forEach(q => console.log(q.Code, q.Price));
};
```

## 常见问题

**Q1：启动服务时提示「未注册或注册已到期」？**
服务启动需有效注册，请先完成[注册](#软件注册)。测试功能不受注册限制。

**Q2：接口返回 `{ "ok": false, "msg": "未选择行情服务器…" }`？**
未选择或未配置行情服务器。请在「设置」中添加 / 选择服务器，并检测连通性。

**Q3：接口返回连接超时？**
行情服务器不可达。请在「设置」中检测服务器连通性，或更换其他服务器。

**Q4：如何访问本机其他 IP？**
默认监听 `127.0.0.1`，仅限本机访问；如需通过本机局域网 IP 访问，在「设置」中把监听地址改为 `0.0.0.0`。

**Q5：端口被占用？**
在「设置」中修改端口号（默认 8888），保存后重新启动服务。

**Q6：服务器可以正常连接，但获取不到数据？**
使用「测试」功能检查数据获取情况，重点看各类 K 线返回数量：若为 0，说明服务器端数据有问题，请更换其他服务器。

**Q7：WebSocket 连上了，却一直收不到行情？**
两种常见原因：① **没有发送 `subscribe`** —— 建连只打通链路，必须发订阅帧才会推送；② 正处于**非活跃时段**（午休 / 盘后 / 周末 / 节假日），此时只在订阅 / 订阅变更时补推一帧最后快照。若收到 `error` 帧，按 `msg` 提示排查（例如超过 8000 只单连接上限）。

**Q8：测试台行情表只看到买一 / 卖一，五档在哪？**
行情表默认就是**五档**视图（买 1~5 价/量 + 卖 1~5 价/量，共 20 列）。若当前显示的是 13 列精简版，点表格顶部 **`五档`** 按钮切回即可；原始字段名（`Bid1` / `BidVol1` …）可悬停表头查看。
